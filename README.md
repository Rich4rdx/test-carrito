# 🛒 Simulación de Carrito de Compras

Proyecto desarrollado con **HTML, CSS y JavaScript puro**, aplicando manipulación del DOM y persistencia con LocalStorage.

---

## 🚀 Descripción

Aplicación web que simula un carrito de compras donde se pueden:

- Listar productos en tarjetas (cards)
- Agregar productos al carrito
- Incrementar y disminuir cantidades
- Eliminar productos
- Vaciar el carrito
- Calcular subtotal dinámicamente
- Persistir datos usando LocalStorage

---

## 🛠 Tecnologías utilizadas

- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (Vanilla JS)
- LocalStorage
